### 1. GitButler

**Vertical:** AI Developer Tools | **Total Raised to Date:** $17M | **Stage:** Series A | **NVIDIA Tech Alignment:** 🟢 Strong potential

**What we do:** GitButler is an AI-native Git client that redesigns version control for agentic coding workflows. Rather than working one branch at a time, developers can manage multiple parallel workstreams simultaneously, with unlimited undo and seamless handoffs to AI coding agents. Founded by Scott Chacon (GitHub co-founder) and Kiril Martini; built from the ground up around the assumption that AI agents will write most code.

**Today's interesting [article](https://siliconangle.com/2026/04/08/gitbutler-raises-17m-simplify-git-workflows-developers/):** a16z led GitButler's $17M Series A — the firm's first dedicated investment in AI developer tooling infrastructure (as distinct from AI coding assistants). The bet is that the Git workflow itself is the next bottleneck as AI agents start generating code faster than humans can review, merge, and ship it.

**Investors:** a16z (lead), Fly Ventures, A Capital

**NVIDIA Relevancy:** The inference infrastructure powering AI coding agents — Claude, Cursor, GitHub Copilot — runs on H100/B200 clusters; TensorRT-LLM and NIM microservices are directly relevant to the backend that GitButler's agent integrations depend on. As agentic coding scales, the GPU demand per developer workflow compounds significantly.

## Interesting Trends

1. **Defense is the new anchor LP for hard-tech rounds** — Three companies in this briefing (Starfish Space via Shield Capital, Portal Space Systems via Booz Allen Ventures, Flashpass via J2 Ventures) have defense-specialist investors as leads or co-leads. This isn't just defense startups raising — it's a structural shift where defense VCs are co-leading rounds alongside commercial firms, treating physical AI, space, and workforce infrastructure as national security bets. NVIDIA's Federal/Defense vertical is directly in the path of this capital flow.

2. **The APAC data sovereignty gap is now fundable** — Nava's $22M Series A from Greenoaks reflects a thesis that APAC governments and regulated enterprises will not route AI workloads through US hyperscalers, creating a durable market for regional GPU cloud infrastructure built on NVIDIA hardware. This mirrors what sovereign AI DGX programs represent at the government level — but Nava is building the commercial cloud layer underneath. Watch for more APAC-focused GPU cloud infrastructure rounds in 2026.

3. **Compliance is becoming the killer app for on-premise NIM** — Haast (enterprise compliance agents), Juno (CPA tax AI with data privacy requirements), and last week's Numos (CFO financial AI) all share the same infrastructure requirement: sensitive professional data that cannot leave the building, requiring on-prem LLM deployment. The pattern across three consecutive briefings now confirms this is a durable category, not a single data point — and it consistently maps to NIM microservices as the enabling technology.
