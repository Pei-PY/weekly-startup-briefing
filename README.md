# Daily Startup Briefing

Daily AI and tech startup news briefings for the NVIDIA Inception team, generated by Claude Code.

## What it does

Each briefing covers the top 10 startup stories of the day, filtered for:

- **Stage**: Pre-seed through Series D (no public companies)
- **Sectors**: AI/ML, SaaS, developer tools, deep tech, robotics, consumer tech
- **Topics**: Funding rounds, acquisitions, product launches, major pivots
- **Sources**: TechCrunch, Y Combinator/HN, Product Hunt, VentureBeat, Business Insider, Fortune

## Structure

```
briefings/          # Daily briefing files (YYYY-MM-DD-briefing.md)
docs/               # Reference docs (NVIDIA Inception, tech stack)
skills/             # Claude Code skill definition
CLAUDE.md           # Project instructions for Claude Code
```

## Usage

In Claude Code, run:

```
/startup-briefing
```

This researches the day's top startup news and saves a briefing to `briefings/`.
